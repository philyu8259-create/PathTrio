# PathTrio Asset Prompt Pack (GPT Image)

Purpose: generate original, non-copyright UI art for PathTrio featuring **Trio Pal** as a friendly abstract path/star/runner companion.

## Asset naming and generation targets

| Asset name (in repo) | Target use | Source render size | Asset set scale mapping |
| --- | --- | --- | --- |
| `TrioPalMascot` | Primary companion badge in header/feature card | 2048 x 2048 | 1x/2x/3x -> 256 / 512 / 768 |
| `TrioPalWalkIllustration` | Walk-mode onboarding or empty-state UI card support art | 2048 x 2048 | 1x/2x/3x -> 256 / 512 / 768 |
| `TrioPalRunIllustration` | Run-mode onboarding or empty-state UI card support art | 2048 x 2048 | 1x/2x/3x -> 256 / 512 / 768 |
| `TrioPalRideIllustration` | Ride-mode onboarding or empty-state UI card support art | 2048 x 2048 | 1x/2x/3x -> 256 / 512 / 768 |

## Prompts

1) `TrioPalMascot`
- Prompt:
  - *"Create a clean, original mascot illustration in flat cartoon style: Trio Pal is a cheerful abstract companion made from path-like loops, a star-shaped head, and a gentle runner silhouette. Keep it kid-safe, friendly, and not realistic. Trio Pal should look active and welcoming, with a circular composition, thick rounded outlines, subtle gradients, soft paper-like texture feel, and no text. Style: bright modern app icon, no IP-specific character traits, no animal references, no bears. Output 2048x2048."*

2) `TrioPalWalkIllustration`
- Prompt:
  - *"Generate a minimal vector-like iOS app illustration for walking mode with Trio Pal guiding a user along a winding path. Use warm greens/teal, abstract hills, small waypoint markers, and geometric UI-friendly shapes. Keep it non-photorealistic, no real people, no logos, no copyrighted characters. Leave room for UI padding around the edges. Output 2048x2048."*

3) `TrioPalRunIllustration`
- Prompt:
  - *"Generate a playful running-mode UI illustration for a fitness app: Trio Pal is a stylized route companion made of line-work trails and a star-like badge, with speed lines and dynamic arcs suggesting movement. Keep it flat, icon-friendly, and non-realistic. Use energetic accent colors and avoid copyrighted visual references or photos. Output 2048x2048."*

4) `TrioPalRideIllustration`
- Prompt:
  - *"Generate a clean bicycle-mode fitness illustration for a mobile app: Trio Pal guides a rider along a clean route map with looped path graphics, gentle perspective, and circular route markers. Use cool blue-violet accents, geometric shapes, rounded forms, and clear contrast against flat terrain panels. Keep it friendly, abstract, and original. Output 2048x2048."*
